# Glossary (EN / ES)

Terms used in this project. One line each; link a concept card when there is one.

| English                  | Español                    | Meaning                                                                |
| ------------------------ | -------------------------- | ---------------------------------------------------------------------- |
| Acceptance criteria (AC) | Criterios de aceptación    | Observable conditions a story must satisfy to be accepted              |
| Refinement               | Refinamiento               | Session where the team clarifies and sizes upcoming stories            |
| Risk-based testing       | Pruebas basadas en riesgo  | Deciding test depth by likelihood and impact of failure                |
| Smoke test               | Prueba de humo             | Minimal check that a deployment is alive and basically works           |
| Regression test          | Prueba de regresión        | Check that existing behaviour still works after a change               |
| Flaky test               | Prueba inestable           | A test that passes and fails without code changes                      |
| Release validation       | Validación de release      | Evidence-based decision that a release candidate can be promoted       |
| Escaped defect           | Defecto escapado           | A bug that reached a later stage than where it should have been caught |
| Contract test            | Prueba de contrato         | Verifies a service honours its published interface (e.g. OpenAPI)      |
| Feedback loop            | Ciclo de retroalimentación | Time between making a change and learning whether it is correct        |
| Quality gate             | Puerta de calidad          | A check that must pass before work moves forward                       |
| Postmortem               | Análisis post-incidente    | Blameless write-up of a failure: cause, diagnosis path, lessons        |
| Exploratory testing      | Pruebas exploratorias      | Simultaneous learning, test design and execution, guided by a charter  |
| Charter                  | Carta de exploración       | Short statement of the mission for an exploratory session              |
| Definition of Done (DoD) | Definición de hecho        | Checklist that makes "done" mean the same for everyone                 |
