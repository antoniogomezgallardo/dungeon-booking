# Concept cards

One card per Quality Engineering concept, written when the concept is first applied in this
project. Each card follows the same structure so they are easy to compare and revisit:

1. **Problem** we hit (concrete, from this project)
2. **Concept** explained for someone who has never seen it
3. **How we applied it here** (links to the real PR, test, commit or issue)
4. **Pitfalls** we fell into or avoided
5. **Further reading**
