# Learning layer

This folder turns the project into living, pedagogical documentation of Quality Engineering.
Everything here links to the real artefact (PR, test, commit, issue) where it happened, so a
reader can see the idea and the evidence side by side.

| Document                                               | What                                                                                                                                             |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| [guia-de-orientacion.es.md](guia-de-orientacion.es.md) | Orientation guide for the QAE (in Spanish, the one exception): product, simulation, architecture, repository map, GitHub, how to start a session |
| [curriculum.md](curriculum.md)                         | Learning goals mapped to sprints and product features                                                                                            |
| `sprint-NN.md`                                         | Journal of each sprint: refinement, planning, QA reviews, release, retro, metrics, escaped defects and their lessons                             |
| [concepts/](concepts/README.md)                        | One card per QE concept: problem → concept → how we applied it here → pitfalls → further reading                                                 |
| [glossary.md](glossary.md)                             | English terms with Spanish translation and a one-line meaning                                                                                    |
| [../postmortems/](../postmortems/README.md)            | Investigations of complex failures: the debugging path, not just the fix                                                                         |

How to read it if you are new to QE: start with the curriculum, then read sprint journals in
order, opening each concept card the first time it is linked.
